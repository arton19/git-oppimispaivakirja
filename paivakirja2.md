# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

GitHubin käyttö tuntui mielestäni selkeältä ja materiaalin tehtävät ja tehtävänannot olivat selkeitä. Huomasin, että tagit ja haarat eivät siirry automaattisesti GitHubiin. Sekoilin hieman terminaalin kanssa ja en ole ihan sata varma sainko tallennettua oikean version aikaisemmasta päiväkirja 1:sestä.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git remote add origin osoite | määrittää etärepositorion nimelle origin |
| git remote -v | näyttää etärepositorioiden osoitteet |
| git push | vie nykyisen haaran uudet talletukset etärepoon |
| git pull | hakee ja yhdistää etämuutokset yhdellä komennolla |
| git branch -a | listaa paikalliset ja etähaarat |
