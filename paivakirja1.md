# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Tein tehtävän 1 kokonaan tietokoneen komentokehotteen kautta. Minulla tuli pari ongelmaa vastaan tehtävässä 2 ja vaihdoin gitbash:iin. Tehtävästä 3 eteenpäin käytin VS Codea. Materiaaleista löytyi aikalailla kaikki asiat ja pienet epäselvyydet selvisi helposti googlaamalla. Ainoa epäselvä asia oli se, että mielestäni hello.html vaihdettiin index.html:ksi, mutta tehtävässä 4 puhuttiin taas hello.html:stä. git status oli myös erittäin hyödyllinen komento, jota yritin käyttää mahdollisimman paljon.

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git config --global user.name "nimi" | Asettaa talletuksiin tallentuvan tekijän nimen |
| git init | Luo nykyiseen hakemistoon uuden repositorion |
| git status | Näyttää työtilan ja valmistelualueen tilanteen |
| git add "tiedoston nimi" | Lisää muutokset seuraavaan talletukseen |
| git commit -m "viesti" | Tallentaa valmistelualueen muutokset historiaan |
| git log | Näyttää talletushistorian |
| git tag nimi | Lisää tunnisteen viimeisimpään talletukseen |
| git branch | Listaa haarat |
| git clone osoite | Kopioi etärepositorion koneelle |
